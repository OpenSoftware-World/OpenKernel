# OpenKernel Documentation / OpenKernel Dokümantasyonu

The full documentation set exists in two languages. Each folder holds the same documents with the same file names; only the language differs.

Döküman setinin tamamı iki dilde mevcuttur. Her klasör aynı dosya adlarına sahip aynı dökümanları içerir; yalnızca dil farklıdır.

| Language / Dil | Index / Dizin |
|---|---|
| English | [docs/en/README.md](en/README.md) |
| Türkçe | [docs/tr/README.md](tr/README.md) |

---

**English** - Read the documents in the numbered order (01 to 10). Every document has a "previous" and "next" link at the top and bottom so you can move through the set like pages in a book. Start at the [documentation index](en/README.md).

**Türkçe** - Dökümanları numaralı sırayla (01'den 10'a kadar) okuyun. Her dökümanın üst ve alt kısmında "önceki" ve "sonraki" bağlantıları vardır; set boyunca kitap sayfaları gibi ilerleyebilirsiniz. [Belge dizini](tr/README.md) ile başlayın.

> **Before you start / Başlamadan önce:** OpenKernel compiles and links out of the box (`make` produces `build/os.bin`), but it does not boot: it is a kernel *library* that expects you to supply your own bootloader and entry point. Read [09 - Project Status](en/09-project-status.md) early if your goal is to get something running.
>
> OpenKernel kutudan çıktığı gibi derlenir ve bağlanır (`make` ile `build/os.bin` üretilir), ancak önyüklenmez: sizin kendi önyükleyicinizi ve giriş noktanızı sağlamanızı bekleyen bir çekirdek *kütüphanesi*dir. Amacınız bir şeyi çalıştırmaksa [09 - Proje Durumu](tr/09-project-status.md) dökümanını okuyun.
